# Information System for Reporting Scientific Publications and Scientometric Indicators with Automated Bibliographic Verification

**Информационна система за отчитане на научните публикации и наукометричните показатели с автоматизирана библиографска проверка**

A. Madzharov, N. Chehlarova, I. Gaidarski — Лаборатория „Безпилотни роботизирани системи“ (URSlab), Институт по роботика – БАН · https://urs.ir.bas.bg

Версия 1.0.0 на системата (= v1.8.0 на хранилището, вж. `CHANGELOG.md`). Как да се цитира — `CITATION.cff`.

## Какво прави
- **Двуезичен сайт** (Astro, статичен): български на `/`, английски на `/en/`.
- **Нова публикация през формата** → заявка в GitHub → проверка в APA 7 и на DOI / ISSN / ISBN в публичните регистри
  (doi.org, Crossref, DataCite, НАЦИД НРС, ISSN Portal, Open Library) → публикуване без ръчна намеса; връщане с една отметка.
- **Годишни страници, „Обобщен отчет“** на всеки потребител, филтри, CSV, дял на авторите от ИР.
- **Цитирания:** въвеждане през формата с доказателство (DOI / линк / PDF); месечно автоматично търсене (OpenAlex, OpenCitations,
  Semantic Scholar) с предварителна проверка и потвърждаване с една отметка; без самоцитирания.
- **Индексиране (Б1–Б3):** сверка на изданието със списъците на Scopus и Web of Science и предложен показател Д-12 / Д-13 / Д-14;
  научно рецензиране по НРС на НАЦИД (Б2).
- **„Точки НАЦИД“ (Б4):** Минималните национални изисквания, Област 5; изключване на представеното в предишни процедури
  (регистър на НАЦИД); стратегия за следващата длъжност — PDF по имейл само до потребителя и ръководителя.

## Ръководства
- `CONTRIBUTING.md` — за потребителите (профил, нова публикация, цитирания, „Точки НАЦИД“, писма).
- `public/docs/URSlab-rakovodstvo.pdf` / `.pptx` — презентация за нов потребител.
- `public/docs/URSlab-citirania.pdf` — „Помощ: цитирания“.
- `CLAUDE.md` — техническо описание на структурата (на английски).

## Работа локално
```
npm install
npm run dev     # http://localhost:4321
npm run build   # готовият сайт е в dist/
```
Данните, въведени през формата, са в клона `data` (в `main` — празни копия); преди изграждане с тях:
`git fetch origin data && git checkout FETCH_HEAD -- src/data/contrib.json src/data/citations`.

## Структура
| Път | Съдържание |
|---|---|
| `src/data/` | съдържанието: състав, публикации по години, цитирания, НАЦИД, проекти, текстове |
| `src/views/`, `src/pages/` | изгледи и маршрути (BG и EN) |
| `src/lib/pubSchema.js` | правилата за проверка — общи за формата и за GitHub |
| `scripts/` | автоматизацията: регистри, цитирания, индексиране, писма, ръководства |
| `.github/workflows/` | публикуване, цитиране, търсене, „Точки НАЦИД“, изграждане и качване |
