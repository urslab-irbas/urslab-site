# Сайт на Лаборатория „Безпилотни роботизирани системи“ (URSlab), ИР–БАН

Статичен двуезичен сайт (Astro). Български на `/`, английски на `/en/`; бутонът в менюто води към същата страница на другия език.

## Как се редактира съдържанието (без програмиране)
Целият текст е в `src/data/`:
| Файл | Какво съдържа |
|---|---|
| `team/*.ts` | Състав: по един файл на човек (име BG/EN, длъжност, ORCID, интереси, снимка); редът е в `team/index.ts` |
| `publications.ts` | Публикации (нова = нов запис най-отгоре), DOI, филтри |
| `content.ts` | Текст „За нас“, направления, проекти, услуги, контакти, менюта |

Снимки: `public/images/team/` (и `photo: "ime.jpg"` в профила на човека) и `public/images/gallery/` (показват се автоматично на началната страница).

## Работа на компютъра (Windows)
1. Инсталирайте Node.js LTS (https://nodejs.org) и VS Code (по-удобен от Visual Studio за уеб).
2. В папката на проекта: `npm install`, после `npm run dev` → http://localhost:4321 (промените се виждат веднага).
3. `npm run build` → готовият сайт е в папка `dist/`.

## Публикуване на urs.ir.bas.bg
Вариант А (най-прост): съдържанието на `dist/` се качва в уеб-директорията на urs.ir.bas.bg (FTP/SFTP/cPanel) на мястото на WordPress. Преди това — архив на WordPress.
Вариант Б: GitHub хранилище + GitHub Pages (или Cloudflare Pages) с автоматично публикуване при всяка промяна; администраторът на ir.bas.bg насочва DNS записа `urs` (CNAME) към него.
