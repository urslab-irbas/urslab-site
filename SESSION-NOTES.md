# URSlab сайт — състояние на проекта (към 01.10.2026)

Този файл е публичен (хранилището е публично). Тук няма пароли, адреси на сървъра и данни за достъп.

## Как работи
- Статичен двуезичен сайт (Astro): български на `/`, английски на `/en/`. Публикуван на https://urs.ir.bas.bg.
- Кодът е в GitHub: `urslab-irbas/urslab-site` (потребителски акаунт, не организация).
- **Merge в `main` = сайтът се обновява сам** (~1 мин.) чрез `.github/workflows/deploy.yml`.
  Данните за достъп до сървъра са в Settings → Secrets → Actions (`DEPLOY_*`). При смяна на паролата на сървъра — обновете и `DEPLOY_PASSWORD`.
- Ръчно публикуване без промяна: Actions → Deploy to urs.ir.bas.bg → Run workflow.
- Всяка промяна минава през Pull Request. Ръководителят одобрява; за собствени промени — отметка „Merge without waiting… (bypass rules)“.
- Защита на `main`: ruleset `main-protection` (PR + 1 одобрение + проверка `build`).
